Udacity _Sudoku Solver_ project: extend a constraint-satisfaction Sudoku agent to solve diagonal puzzles and implement the naked twins strategy.

Setup with [uv](https://docs.astral.sh/uv/): `uv venv && source venv/bin/activate && uv pip install -r requirements.txt`

Then run the local tests with `python -m unittest -v`. Complete the TODOs in `solution.py`. Visualize a solution with `python solution.py` (requires pygame).

Starter code is from Udacity (MIT).

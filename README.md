Udacity _Sudoku Solver_ project: extend a constraint-satisfaction Sudoku agent to solve diagonal puzzles and implement the naked twins strategy.

Setup with [uv](https://docs.astral.sh/uv/): `uv venv && source venv/bin/activate && uv pip install -r requirements.txt`. This will install pygame.

Run the code with `python solution.py` (uses pygame for visualization). Run local tests with `python -m unittest -v`.
